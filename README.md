# Metalduro — сайт

Next.js 16 (App Router) + Tailwind CSS 4. Русская версия.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # продакшен
```

## Supabase и авторизация

Локальная интеграция Supabase подготовлена, но требует созданного проекта и переменных
из `.env.example`. Миграции, RLS, RPC, приватный Storage и инструкция владельца находятся
в `supabase/` и `docs/SUPABASE_SETUP.md`.

Без переменных Supabase публичный сайт продолжает работать, а страницы авторизации и
кабинетов показывают понятное сообщение о необходимости настройки.

## Фото

1. Скачайте фото из папки Google Drive в `_photos_src/` (имена файлов не меняйте, HEIC можно оставить как есть).
2. Выполните `npm run photos` — скрипт сконвертирует HEIC, уменьшит до 2000 px и положит файлы в `public/photos/` под нужными именами.

Соответствие «место на сайте → файл на Drive» — в `scripts/prepare-photos.mjs`.
Пока какого-то фото нет, на его месте показывается заштрихованная заглушка с подписью.
Можно и просто положить свой файл в `public/photos/<ключ>.jpg` (например `pack-1.jpg` — «Пример упаковки»).

## Где что править

| Что | Файл |
| --- | --- |
| Все тексты главной, контакты, ставки €/кг, города, история отправок, FAQ | `src/content/site.ts` |
| Гайды | `src/content/guides.ts` |
| Юридические страницы | `src/app/legal/*/page.tsx` (данные компании берутся из `contacts` в `site.ts`) |
| Цвета, шрифты, без скруглений | `src/app/globals.css` (`@theme`) |
| Калькулятор | `src/components/Calculator.tsx` |
| Прием заявок | `src/app/api/lead/route.ts` — безопасная заглушка, возвращает HTTP 503 без логирования персональных данных |

## Стиль

Актуальный интерфейс следует тёмной визуальной системе последнего GitHub-дизайна:
DM Sans, фон `#0b0b0c`, светлый текст и акцент `#ff5c39`. Фактические токены находятся
в `src/app/globals.css`, а публичные паттерны — в `src/app/home-ref.css`.

`STYLE-GUIDE.md` описывает предыдущую светлую систему и требует согласования с владельцем
дизайна перед дальнейшим использованием.
